AP Creative Dashboard — Site Audit

Static vanilla HTML prototype generated from the Next.js codebase (internal-apcreative). Open this file in a browser. Use the buttons below to switch views.

1. Executive summary

This is an internal dashboard for AP Creative: brand officers, supervisors, executives, and full-stack developers manage content approvals, tasks, reminders, daily progress, ads campaigns, and analytics. The live app is a Next.js App Router SPA with server components, PostgreSQL, and cookie-based Better Auth — not a static site.

Static HTML limitations: No real auth, API, database, drag-and-drop, dialogs, rich text (Plate.js), charts (Recharts), file uploads, or server actions. Prototypes below mirror layout and neo-brutal styling only.

5. Shared UI patterns (audit)

  • DashboardShell — Sidebar (17rem) + sticky header (title from route) + clock badge + dotted main background.
  • BoardSection — Card wrapper for kanban boards; title row + optional dashed empty-state + actions right-aligned.
  • Kanban — Horizontal scroll columns; cards with hard shadow; employee approvals use 6 columns (Pending → Published).
  • Data tables — Bordered scroll area, sticky header, pagination component (Account Control, approvals table view).
  • Neo-brutal — 2px ink borders, --shadow-hard, cream background, navy sidebar active state.
